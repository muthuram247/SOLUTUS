# SOLUTUS

### From Problem to Resolution

SOLUTUS is an AI-powered student support platform designed to help
college students safely report, track, and resolve campus and hostel issues.

## Problem

Students face problems related to hostels, food, academics, faculty,
infrastructure, outpass, and administration. Many students hesitate to
report these issues or struggle to follow up on them.

## Solution

SOLUTUS provides a single platform where students can:

- Report issues
- Choose Anonymous, Confidential, or Identified reporting
- Get AI-based issue categorization
- Send complaints to the appropriate department
- Track complaint status
- Receive escalation for unresolved issues
- Submit digital outpass requests

## Workflow
